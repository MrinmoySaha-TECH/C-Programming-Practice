# C Programming Practice

This repository contains my C programming practice programs while
learning fundamental concepts of the C programming language.

## Topics Covered

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Recursion
- Pointers
- Pattern Printing
- Basic Problem Solving
- Random Number Generation

## Programs

| Program | Concept |
|---|---|
| fibonacci-series.c | Recursion |
| force-calculation.c | Functions |
| income_tax.c | Conditional Statements |
| leapYear.c | Conditional Statements |
| multiplication.c | Loops |
| number-guessing.c | Loops + Random Numbers |
| pointer.c | Pointers |
| star-pattern.c | Nested Loops |

## Goal

To build strong fundamentals in C programming and prepare for
Data Structures and Algorithms.
